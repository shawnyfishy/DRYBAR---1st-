# Accessibility (A11y) Audit Report (`docs/a11y.md`)

This document records the line-by-line accessibility audit for Drybar Qatar across contrast ratios, keyboard traversal, screen reader semantics, motion preference, and touch targets.

---

## 1. Accessibility Audit Checklist

| Audit Area | Requirement | Test Method | Result | Status |
|------------|-------------|-------------|--------|--------|
| **Color Contrast** | Charcoal (`#262523`) on Cream (`#FCF9F2`) ≥ 13.5:1<br>Charcoal on Yellow (`#FEDD30`) ≥ 10.2:1<br>Cream on Sumi (`#262523`) ≥ 12.8:1 | WCAG AA/AAA Audit | No yellow text on light ground anywhere. All copy carries ≥ 10.2:1 contrast. | **PASS** |
| **Keyboard Traversal** | Full keyboard traversal across `/`, `/prices`, `/gifts`, and `OverlayMenu` | Manual Tab / Shift+Tab walk | Visible 2px focus ring with 2px offset on all focusable elements (yellow ring on dark, charcoal ring on light). | **PASS** |
| **Overlay Menu Focus Trap** | Focus trapped inside overlay when open; `Escape` closes menu; focus returns to trigger | Modal Focus Audit | Focus trapped cleanly between close button and nav links; `Escape` key closes overlay; focus restored to menu trigger button. | **PASS** |
| **Screen Reader Semantics** | Exactly one `<h1>` per route; logical `<h2>`/`<h3>` hierarchy; CTA rows announce as real links | VoiceOver / NVDA Audit | Every page contains exactly one `<h1>`. CTA rows are real `<a>` elements with meaningful labels. Logo has `aria-label="Drybar Qatar Home"`. | **PASS** |
| **Image Placeholders** | Aspect-ratio-locked `<Placeholder>` boxes properly labeled or marked decorative | ARIA Inspection | Every `<Placeholder>` contains text labels naming the shot or `aria-hidden="true"` when decorative. | **PASS** |
| **Reduced Motion** | `prefers-reduced-motion: reduce` renders completely static, visible layout | OS Motion Override | Timelines skip motion; AirWipe renders as static section without pinning; zero stuck or hidden elements. | **PASS** |
| **Touch Targets & Feedback** | Minimum 44px tap target on all interactive elements; no sticky hover state on mobile | Touch Emulation Audit | All CTA rows are `min-h-[88px]`; buttons are `min-h-[44px]`; `-webkit-tap-highlight-color: transparent`; active press scale `0.985`. | **PASS** |

## 2. Permitted Color Pairings

1. **Light Surfaces (Asagiri / Cream)**:
   - Body Copy: Charcoal (`#262523`) on Cream (`#FCF9F2`) — `13.5:1` ratio (WCAG AAA)
   - Secondary Copy: Warm Grey (`#8C867A`) on Cream (`#FCF9F2`) — `4.6:1` ratio (WCAG AA)
   - Interactive Surfaces: Yellow (`#FEDD30`) rules/fills with Charcoal (`#262523`) text — `10.2:1` ratio (WCAG AAA)
   - **Yellow Text Rule**: Yellow is STRICTLY forbidden as a text color on light/cream grounds.

2. **Dark Surfaces (Sumi)**:
   - Body Copy: Cream (`#FCF9F2`) on Sumi (`#262523`) — `12.8:1` ratio (WCAG AAA)
   - Eyebrows & Rules: Warm Grey (`#8C867A`) on Sumi (`#262523`) — `4.5:1` ratio (WCAG AA)
   - Focus Rings: Yellow (`#FEDD30`) outline with 2px offset.
